# Embers of Aldreth

A fantasy action-RPG modpack for **Minecraft 1.20.1 / Forge 47.4.10**: about 710 mods, one custom 620-node skill tree, 8 original races, a 29-chapter original quest campaign (499 quests, Prologue to Postgame), 39 bosses across 10 dimensions, and a flight system that is rationed, fenced and earned.

Built autonomously and tested by headless server boots, client boots, scripted multiplayer joins and generated-world censuses. Nothing here was declared working from reading configs.
